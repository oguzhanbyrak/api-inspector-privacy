RequestLens Privacy Policy

Last updated: August 17, 2026

RequestLens is a Chrome extension designed to help developers inspect, debug, and replay API and network requests made by their Chrome browser.

1. Information the Extension Processes

RequestLens processes network request and response information from the browser tab being inspected. Depending on the requests made by the website, this information may include:

  • Request URLs
  • HTTP methods
  • Request and response headers
  • Request and response bodies
  • HTTP status codes
  • Request timing and duration information
  • Request errors and lifecycle information

The content of a request or response may contain information provided by the website or web application being inspected. Depending on the website, this information could potentially include authentication tokens, session identifiers, personal information, or other sensitive data.

RequestLens does not intentionally collect information unrelated to its network inspection functionality.

2. How Information Is Used

Information processed by RequestLens is used solely to provide its core functionality, including:

  • Inspecting API and network requests
  • Viewing request and response details
  • Filtering captured requests
  • Reviewing captured request information
  • Replaying requests
  • Editing and replaying requests
  • Copying requests into formats such as cURL, Fetch, Axios, and Node.js

3. Local Storage

Captured request information and extension state are stored locally within the user's browser using Chrome's extension storage mechanisms.

RequestLens does not operate a remote server for collecting or storing captured request or response data.

Captured request and response data is not sold, rented, or shared with advertisers, data brokers, or other third parties by the developer.

4. Request Replay

When a user explicitly chooses to replay a request, RequestLens sends the replayed request to its intended destination. This communication is initiated by the user's action and is necessary to provide the request replay functionality.

The destination website or API may process the replayed request according to its own privacy policy and terms.

5. Third-Party Services

RequestLens does not use captured request or response data for advertising, profiling, analytics, or marketing purposes.

RequestLens does not sell or transfer captured request or response data to third parties.

6. Data Security

Captured requests may contain sensitive information depending on the website being inspected. RequestLens stores captured request data locally in the user's browser and does not transmit captured request data to the developer's servers.

Users should take care when sharing screenshots, copied requests, logs, or other information obtained through the extension, as such information may contain sensitive data.

7. Data Retention and Deletion

Captured request data remains in the extension's local storage according to the extension's storage behavior and can be removed by the user through the extension or by clearing the extension's stored data.

8. Children's Privacy

RequestLens is a developer tool and is not directed toward children.

9. Changes to This Privacy Policy

This Privacy Policy may be updated when the extension's functionality or data practices change. Any updated version will be made available at this same Privacy Policy URL.

10. Contact

If you have questions about this Privacy Policy or RequestLens, please contact the developer through the support information provided on the RequestLens Chrome Web Store listing.

11. Chrome Web Store Limited Use

RequestLens's handling of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide the extension's single purpose of inspecting, debugging, and replaying API and network requests.
